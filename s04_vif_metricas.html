Sección 04 · Diagnóstico y evaluación

VIF · Train/Test Split · Métricas de Error

Cómo detectar multicolinealidad variable por variable, dividir correctamente los datos para evaluar predicción fuera de muestra, y qué métricas usar para reportar el desempeño del modelo.

4.1 Factor de Inflación de Varianza (VIF)

El VIF mide cuánto se infla la varianza de $\hat{\beta}_j$ debido a la correlación de $x_j$ con los demás regresores. Se calcula regresando cada $x_j$ sobre todas las otras variables y usando el $R^2$ de esa regresión auxiliar:

$$\text{VIF}_j = \frac{1}{1 - R_j^2}$$
Interpretación directa

$\text{VIF}_j = 5$ significa que la varianza de $\hat{\beta}_j$ es 5 veces mayor que si $x_j$ fuera ortogonal a todos los demás regresores. Los intervalos de confianza son $\sqrt{5} \approx 2.24$ veces más anchos.

Número de condición — multicolinealidad global

El número de condición $\kappa(\mathbf{X})$ resume la multicolinealidad de toda la matriz, no variable por variable:

$$\kappa(\mathbf{X}) = \sqrt{\frac{\lambda_{\max}(\mathbf{X}^\top\mathbf{X})}{\lambda_{\min}(\mathbf{X}^\top\mathbf{X})}}$$
κ < 30: sin problema de multicolinealidad 30 ≤ κ < 100: multicolinealidad moderada κ ≥ 100: multicolinealidad severa → revisar especificación

4.2 Train / Test Split

Dividir los datos en entrenamiento y prueba permite evaluar la capacidad predictiva real del modelo en observaciones que no usó para estimar los parámetros. El ajuste en muestra ($R^2$ train) siempre es optimista; el ajuste fuera de muestra ($R^2$ test) es el indicador honesto.

Ajusta la proporción

20%
Train: 16,497 obs.
Test: 4,124
Regla crítica: nunca escalar con datos de test

La media y desviación estándar del StandardScaler se ajustan solo con los datos de entrenamiento. Aplicar el scaler ajustado en train al conjunto de test. Si ajustas con toda la muestra introduces data leakage: el modelo "sabe" indirectamente el rango de los datos de prueba durante el entrenamiento.

Validación cruzada K-Fold

Para estimar el error de predicción con menor varianza que un solo split, se usa K-Fold: los datos se dividen en $K$ partes iguales, y el modelo se entrena $K$ veces usando $K-1$ folds como entrenamiento y 1 como prueba.

K = 5
Ventaja de K-Fold sobre un solo split

Con un solo split 80/20 el error estimado depende de qué observaciones cayeron en cada conjunto (varianza alta). Con 10-Fold cada observación es parte del conjunto de prueba exactamente una vez — la estimación del error es más estable y usa toda la muestra para entrenamiento en alguna iteración.

4.3 Métricas de Error

Evaluar un modelo requiere más de una métrica. Cada una mide un aspecto distinto del error y tiene distintas sensibilidades a outliers y a la escala de $y$.

Métricas de ajuste en muestra (train)

$R^2$ — coeficiente de determinación

$$R^2 = 1 - \frac{\text{SSE}}{\text{SST}} \in [0,1]$$

Proporción de varianza de $y$ explicada por el modelo. Nunca disminuye al agregar regresores.

$\bar{R}^2$ — $R^2$ ajustado

$$\bar{R}^2 = 1 - \frac{n-1}{n-k-1}(1-R^2)$$

Penaliza por el número de regresores $k$. Puede disminuir al agregar variables irrelevantes. Preferir sobre $R^2$ para comparar modelos.

Criterios de información — AIC y BIC

Los criterios de información permiten comparar modelos con distinto número de parámetros, penalizando la complejidad. A diferencia del $R^2$, que siempre mejora al agregar variables, AIC y BIC pueden empeorar si la variable agregada no aporta suficiente poder explicativo.

AIC — Criterio de Akaike

$$\text{AIC} = n \cdot \ln\!\left(\frac{\text{SSE}}{n}\right) + 2(k+1)$$

Menor AIC = mejor. Penaliza por el número de parámetros. Útil para comparar modelos no anidados.

BIC — Criterio Bayesiano (Schwarz)

$$\text{BIC} = n \cdot \ln\!\left(\frac{\text{SSE}}{n}\right) + (k+1) \cdot \ln(n)$$

Penaliza más fuerte que AIC cuando $n$ es grande. Tiende a seleccionar modelos más parsimoniosos.

AspectoAICBIC
Penalización2(k+1) — fija(k+1)·ln(n) — crece con n

Ejemplo numérico — California Housing

Con $n = 16{,}497$, $k = 8$ regresores, $\text{SSE}_{\text{train}} = 2{,}043.1$ (en log-escala):

AIC = 16,497 · ln(2043.1/16497) + 2·(8+1) = 16,497 · (−2.0886) + 18 = −34,437 BIC = 16,497 · ln(0.1238) + 9 · ln(16,497) = −34,455 + 87.4 = −34,368

AIC < BIC porque BIC penaliza más. Si agregamos un regresor irrelevante, AIC subiría ~2 y BIC ~9.7.

Conceptos clave: Grados de libertad, Nivel de confianza y p-value

Grados de libertad (gl)

$$\text{gl} = n - k - 1$$

Observaciones "libres" tras estimar $k+1$ parámetros. Con $n=16{,}497$ y $k=8$: gl $= 16{,}488$. Cuantos más parámetros, menos gl para estimar $\sigma^2$.

Nivel de confianza ($1-\alpha$)

Típicamente 95% ($\alpha = 0.05$)

Si repetimos el muestreo infinitas veces, el 95% de los IC contendrán el verdadero $\beta$. No significa que haya 95% de probabilidad de que $\beta$ esté en nuestro IC.

p-value

$$p = P(|t| \geq |t_{\text{obs}}| \mid H_0)$$

Si $p < \alpha$: rechazamos $H_0: \beta_j=0$ → variable significativa. Si $p \geq \alpha$: no hay evidencia de que $\beta_j \neq 0$.

Significancia estadística ≠ importancia práctica

Con $n$ grande, coeficientes diminutos pueden tener $p < 0.001$. Un $p$-value pequeño dice que el efecto es distinto de cero, no que es grande. Siempre reporta el tamaño del efecto junto con el $p$-value.

Interpretación de resultados

La diferencia entre $R^2$ train (0.641) y test (0.639) es de apenas 0.002 — prácticamente sin sobreajuste. El modelo generaliza bien. El RMSE de ~$67k en escala original indica que la predicción típica se equivoca en ~$67,000 dólares sobre el precio real. El MAPE de 28% sugiere margen de mejora, especialmente en distritos de precio muy bajo donde el error porcentual es mayor.
